### 📚 Case Studies

#### CTRL + THINK: The Art of Artificial Thinking

**Comparative Product Teardown: ChatGPT vs Claude vs Gemini**

A product teardown comparing three leading AI assistants through monetisation, feature prioritisation, UX simplicity, API strategy, user segmentation, and competitive positioning.

**Questions explored:**
- How do the products differ in monetisation and business model?
- How does each product prioritise capabilities and manage complexity?
- How do UX simplicity, distribution, and ecosystem integrations create differentiation?
- How should AI products measure useful outcomes beyond response time?

**Key product perspective:** As model capabilities converge, differentiation increasingly depends on workflows, distribution, trust, ecosystem integration, and the ability to help users reach a usable outcome.

#### READ AI: Research & Clario Product Strategy

**Competitive Product Research and Landing Page Development**

A research and product strategy project analysing Read AI's features, pricing, positioning, customer feedback, and product limitations, followed by the definition and landing-page development of Clario, a proposed AI meeting copilot.

**My work covered:**
- Competitive analysis of features, positioning, pricing, and customer feedback
- User concerns around privacy, recording consent, transcription accuracy, and user control
- Clario's audience, value proposition, positioning, and MVP scope
- Feature prioritisation across meeting summaries, searchable transcripts, smart highlights, cross-platform search, and consent-first capture

**Key product perspective:** AI productivity tools need to be useful and powerful while making privacy, consent, accuracy, and user control visible parts of the product experience.

#### Virtual Teaching Assistant — RAG Question-Answering API

A retrieval-augmented question-answering system for the IIT Madras Tools in Data Science course. It combines course pages and forum discussions to produce grounded answers with source links.

**Highlights**
- Collected and processed course website pages and **4,000+ Discourse posts**
- Built a chunking, embeddings, and cosine-similarity retrieval pipeline
- Enriched retrieved context with adjacent chunks to improve answer grounding
- Supported text questions and optional image input
- Exposed the pipeline through a REST API designed for automated evaluation

**Tech:** Python, FastAPI, SQLite, NumPy, embeddings, LLM APIs, Playwright

🔗 [GitHub Repository](https://github.com/23f2004126/virtualta-project) · [Project Report (PDF)](https://willowy-druid-25583e.netlify.app/project/5.pdf)
